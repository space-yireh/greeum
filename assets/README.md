# 그림체 참고 이미지

`style-reference.png`는 사용자가 제공한 좌측 귀엽게 / 우측 비슷하게 예시입니다. `CARICATURE_STYLE_REFERENCE_LAYOUT=paired`일 때 서버 메모리에서 반으로 선택하여 요청당 한쪽만 보냅니다. cute는 좌측, similar는 우측입니다. funny 전용 예시는 제공되지 않아 좌측의 선화만 빌리고 과장은 프롬프트로 지정합니다. 자른 참조나 방문자 원본 사진은 파일로 저장하지 않습니다. 설정이 없으면 레퍼런스 없이 프롬프트만 사용합니다.

공통 모델은 Sunburst medium 1024×1024로 유지합니다. 결과는 색을 제거한 그레이스케일 PNG이며, 미세한 선과 부드러운 가장자리를 보존하기 위해 픽셀을 검정/흰색 두 값으로 강제하지 않습니다.
